# 07 · 每週配額 + 解鎖碼 + Turnstile（Worker v3）

> 目標：免費版 **每人每週 10 次**；用完可以輸入解鎖碼 **+10 次**；解鎖可加人機驗證防暴力破解。

---

## 1. 目前參數（Worker v3）

| 常數 | 值 | 意思 |
|------|-----|------|
| `WEEKLY_MAX` | **10** | 每個 IP 每週免費次數 |
| `UNLOCK_BONUS` | **10** | 每次輸入解鎖碼加送次數 |
| `RATE_MAX` | 6 / 分鐘 | 防瞬時爆發 |
| 解鎖嘗試 | 5 次 / 10 分鐘 | 防暴力猜密碼 |
| 週界線 | 格林威治時間星期一 00:00 | 即香港時間星期一 08:00 |

> 以 ¥1 ≈ 80 次計，**每週 10 次 × 8 週** 才用完，非常安全。

---

## 2. 部署 Worker v3（Dashboard，3 分鐘）

1. Cloudflare → **Workers & Pages** → 你的 `ziwe-kevin` Worker → **Edit code**
2. 全選刪除 → 貼上 `worker/ziwei-proxy-worker.js`（v3）全文
3. **Deploy**
4. **Settings → Variables and Secrets**，新增：

| Name | Type | 值 |
|------|------|-----|
| `DEEPSEEK_API_KEY` | Secret | 你已有的（唔需要改） |
| **`UNLOCK_PASSWORD`** | **Secret** | **`tccs`** |
| `TURNSTILE_SECRET` | Secret | （可選，見 §4） |

5. 想配額**持久**（唔怕 Worker 重啟歸零）→ §3 加 KV。

### 驗證（瀏覽器 F12 → Console，喺 Pages 頁面開）

```js
fetch("https://ziwe-kevin.www-wongkevin404.workers.dev/quota")
  .then(r => r.json()).then(console.log)
// 期望：{ ok:true, week:"2026-11-16", used:0, limit:10, remaining:10, weeklyMax:10, unlockBonus:10,
//         unlockEnabled:true, turnstileEnabled:false }
```

```js
fetch("https://ziwe-kevin.www-wongkevin404.workers.dev/unlock", {
  method:"POST", headers:{"content-type":"application/json"},
  body: JSON.stringify({ password: "tccs" })
}).then(r => r.json()).then(console.log)
// 期望：{ ok:true, bonus:10, limit:20, remaining:20 }
```

---

## 3.（建議）加 KV，令配額持久

冇 KV 時配額存在 Worker 記憶體：**isolate 重啟就歸零**（可能幾分鐘一次）。

1. Cloudflare → **Storage & Databases → KV** → **Create namespace** → 名 `zwds-quota`
2. Worker → **Settings → Bindings → Add → KV Namespace**
   - Variable name: **`ZWDS_KV`**
   - Namespace: `zwds-quota`
3. **Deploy**

Worker 會自動用 KV（有 binding 就持久，冇就 fallback 記憶體）。

---

## 4.（可選）Turnstile 人機驗證

**只用在「解鎖碼」那一步**（唔會煩到一般使用者）。

1. Cloudflare → **Turnstile** → **Add widget**
   - Widget name: `ziwei-unlock`
   - Hostnames: `wongggggggggggggggggg.github.io`
   - Widget mode: Managed
2. 取得 **Site Key** 與 **Secret Key**
3. **Secret Key** → Worker Secret `TURNSTILE_SECRET`
4. **Site Key** → 前端 `index.html` 的 `CONFIG.TURNSTILE_SITE_KEY`（要重新上載 `index.html`）

> 未設 `TURNSTILE_SECRET` 時，Worker 會自動跳過驗證（graceful），所以可以後加。

---

## 5. 前端會顯示什麼

設定對話框（齒輪）新增「**本週使用次數**」：

```
本週免費 10 次，已用 3 次，剩 7 次（目前上限 10）
[ 解鎖碼 ______ ]  →
用完免費次數時輸入解鎖碼，可再加 10 次（每週一重置）。
```

用完時按「開始解讀」會顯示：
> 本週免費次數已用完（10 次）。輸入解鎖碼可再加 10 次。
並且**自動彈出設定**讓你輸入解鎖碼。

---

## 6. 注意事項（誠實講）

| 項目 | 實情 |
|------|------|
| 配額以 **IP** 計算 | 同一 Wi-Fi 下多部裝置共用；手機 4G 換 IP 可能重新計算 |
| 冇 KV 時 | 配額可能因 Worker 重啟而歸零（所以建議加 KV） |
| 解鎖碼 `tccs` | 只 4 個字，屬**軟性門檻**，朋友之間分享用；唔好當密碼保管機密 |
| Turnstile | 只擋「自動猜解鎖碼」，唔會影響正常解讀 |
| 每週 10 次 | 週界線為 UTC 星期一 00:00 = 香港星期一 08:00 |
